# Churn Radar

Небольшой end-to-end ML-проект, который оценивает вероятность ухода клиента из онлайн-сервиса. Проект сделан как реалистичная работа начинающего разработчика: без сложной инфраструктуры, но с полным путём от данных до веб-демо.

## Что умеет проект

- генерирует воспроизводимый синтетический датасет клиентов;
- обучает Logistic Regression с обработкой числовых и категориальных признаков;
- считает ROC-AUC, accuracy, precision, recall и F1;
- сохраняет обученную модель и метрики;
- показывает прогноз в интерактивном Streamlit-интерфейсе;
- содержит небольшие автоматические тесты.

## Стек

Python, pandas, scikit-learn, Streamlit, joblib, pytest.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e .

python -m churn_predictor.data
python -m churn_predictor.train
streamlit run app.py
```

После запуска откройте адрес из терминала (обычно `http://localhost:8501`).

## Результаты

Фактические метрики после обучения лежат в `reports/metrics.json`. Они считаются на отложенных 25% данных с фиксированным `random_state`, поэтому результат воспроизводим.

Logistic Regression выбрана намеренно: для первого проекта она проще в объяснении, быстро обучается и даёт вероятности. `class_weight="balanced"` помогает модели не игнорировать менее частый класс ушедших клиентов.

## Ограничения

- данные синтетические и не отражают конкретный реальный бизнес;
- модель не проходила A/B-тестирование;
- пороги риска 35% и 65% выбраны для демонстрации, а не оптимизированы по стоимости ошибок.

## Идеи для развития

- сравнить модель с Random Forest или CatBoost;
- добавить SHAP-графики для объяснения прогнозов;
- завернуть прогноз в FastAPI;
- добавить Docker и CI через GitHub Actions.

## Как рассказать о проекте на собеседовании

> Я хотел пройти полный цикл небольшой ML-задачи. Сгенерировал данные с понятными зависимостями, собрал preprocessing и модель в единый sklearn Pipeline, проверил качество на отложенной выборке и сделал простой интерфейс для бизнес-пользователя. Отдельно отметил ограничения: на синтетических данных метрики нельзя переносить на реальный продукт.
