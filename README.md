# Churn Radar

Churn Radar — мой учебный ML-проект для прогнозирования оттока клиентов онлайн-сервиса.

Я сделал этот проект, чтобы пройти полный цикл работы над задачей машинного обучения: от подготовки данных и обучения модели до создания простого веб-интерфейса.

## О проекте

Модель анализирует информацию о клиенте и оценивает вероятность того, что он перестанет пользоваться сервисом.

Для прогноза используются следующие признаки:

- продолжительность использования сервиса;
- ежемесячные расходы;
- количество обращений в поддержку;
- активность пользователя;
- количество просроченных платежей;
- тариф;
- тип контракта;
- наличие автоплатежа.

Данные в проекте синтетические. Я выбрал такой подход, чтобы проект можно было запустить без скачивания сторонних датасетов и ограничений на использование данных.

## Возможности

- генерация воспроизводимого датасета клиентов;
- обработка числовых и категориальных признаков;
- обучение модели Logistic Regression;
- оценка качества на тестовой выборке;
- сохранение обученной модели;
- прогноз вероятности оттока;
- разделение клиентов по уровням риска;
- интерактивный интерфейс на Streamlit;
- автоматические тесты.

## Использованные технологии

- Python
- pandas
- NumPy
- scikit-learn
- Streamlit
- joblib
- pytest

## Результаты модели

На тестовой выборке модель показала следующие результаты:

| Метрика | Значение |
|---|---:|
| ROC-AUC | 0.7439 |
| Accuracy | 0.6720 |
| Precision | 0.4224 |
| Recall | 0.7222 |
| F1-score | 0.5330 |

Для этой задачи я уделил особое внимание Recall, поскольку важно найти как можно больше клиентов с риском ухода.

Метрики намеренно не выглядят идеально: данные содержат шум, поэтому задача больше похожа на реальный ML-кейс.
